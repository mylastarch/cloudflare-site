Write the Pi 400 image

After confirming the correct SD-card device, decompress and write the image with:

zstd -dc mylastarch-pi400-desktop.img.zst | sudo dd of=/dev/sdX bs=4M iflag=fullblock status=progress conv=fsync

Replace /dev/sdX with the whole SD-card device. Choosing the wrong device will overwrite its data.

Important first-login security step

The initial accounts are default / default and root / root. Change both passwords immediately after first boot and before connecting the Pi to an untrusted network. Root SSH login is disabled.

Available at dccwebsite.com, the project is free, open-source, and welcomes contributions of all kinds.
