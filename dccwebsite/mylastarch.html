What You Get

Everything Arch. Nothing to Figure Out.

MYLASTARCH handles the hard parts so you get a production-ready Arch system on day one.

🚀

Friendly Calamares Installer

Calamares 3.4.2 provides a guided graphical installation, getting you from the live ISO to a ready desktop without a command-line setup.

🧰

KDE Plasma 6.7 Desktop

A complete Plasma desktop with Dolphin, Konsole, Kate, Discover, Spectacle, Gwenview, system monitoring, networking, Bluetooth, and firewall integration.

⚡

Current Arch Foundation

Ships with Linux 7.1, current Arch packages, rolling updates, recent AMD and Intel microcode, and broad hardware firmware support.

📦

Flexible Software Management

Install software with Discover, Pamac, Flatpak, Pacman, or Yay. The full Arch repositories, AUR access, and the MYLASTARCH repository are ready to use.

🎨

Useful Applications Included

Start with LibreOffice Fresh, Thunderbird, multimedia support, Gwenview photo tools, Guvcview webcam support, Git, and Gittyup.

🔒

Desktop Hardware Support

Printing, USB printers, Bluetooth, firmware updates, PipeWire audio, network shares, and virtual-machine guest tools are included.

Your Desktop, Your Choice

KDE Plasma Included. Other Desktops Are Up to You.

MYLASTARCH ships with a fully pre-configured KDE Plasma desktop. Arch Linux Tweak Tool (ATT) offers 15 desktop environments and 15 tiling window managers, making it easy to add another option or replace KDE Plasma with the workspace you prefer.

✦ KDE Plasma GNOME XFCE Cinnamon More supported desktops

Arch Linux Tweak Tool provides the desktop-management options. KDE Plasma remains the polished, ready-to-use default included with the ISO.

The Project

Built by the Community, for Everyone

MYLASTARCH started as a personal project to make Arch Linux accessible without sacrificing any of what makes Arch great — rolling releases, massive package selection, and full control.

Available at dccwebsite.com, the project is free, open-source, and welcomes contributions of all kinds.
