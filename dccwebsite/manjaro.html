First Steps After Installing Manjaro Linux

A GUI-focused introduction for people moving from Windows.

On this page Update Manjaro Add software tools to Favorites Open Settings Manager Get to know LibreOffice Understand Linux file paths Set up a printer

Update Manjaro

The first thing to do after installing Manjaro is update the system. At the bottom of the screen, look for the shield-shaped update icon. Hover over it to see whether updates are available.

  1. Select the update icon.
  2. Review the available updates and select Apply.
  3. Enter your user password when authentication is requested.
  4. Approve any additional packages Manjaro needs to install.
  5. Wait for the update process to finish and confirm the system is up to date.

Check the update icon regularly and install new updates when they become available.

Add/Remove Software in Favorites

You will use the Add/Remove Software application often, so it is useful to add it to your Favorites menu.

  1. Open the application menu in the lower-left corner.
  2. Select All Applications.
  3. Find Add/Remove Software and right-click it.
  4. Select Add to Favorites.

Open Settings Manager

Settings Manager is another useful application. Open the application menu and select the wrench-shaped button near your username. This launches the Settings Manager, where you can customize the desktop and system.

Get to Know LibreOffice

LibreOffice is the office suite commonly installed with Manjaro. Its applications correspond to familiar Microsoft Office programs:

Microsoft Word
LibreOffice Writer
Microsoft Excel
LibreOffice Calc
Microsoft Access
LibreOffice Base
Microsoft PowerPoint
LibreOffice Impress

LibreOffice can open most Microsoft Office documents. When saving changes, it may ask whether you want to use a LibreOffice or Microsoft format. In many cases, you can continue using the Microsoft format when sharing files with Microsoft Office users.

Understand Linux File Paths

Windows organizes storage around drive letters such as C:. Linux starts with a single root directory, written as /, and attaches other directories and devices beneath it.

  • User files are normally stored under /home.
  • System configuration files are stored under /etc.
  • External devices may be mounted under /mnt or /media.

Windows: C:\Users\user\Documents

Linux: /home/user/Documents

Windows paths use backslashes (\), while Linux paths use forward slashes (/).

Set Up a Printer

Manjaro may not configure your printer automatically. The following GUI steps use the system-config-printer package and work well for many network printers:

  1. Open Add/Remove Software.
  2. Search for system-config-printer.
  3. Select the package for installation and follow the prompts.
  4. After installation, open the application menu and search for Print Settings.
  5. Select Add, then choose Network Printer if the printer is connected to your network.
  6. Select the appropriate printer and continue.
  7. If Manjaro finds a suitable driver, apply the configuration.
  8. Select Print Test Page to confirm that everything works.

Printer models differ, so additional manufacturer software may occasionally be required.
