First things to do once you have installed Manjaro Linux


What we are going to do is go over some of the first steps you should do right after you install Manjaro Linux. Now since we are coming from being a Windows user I am going to look at this a just using the GUI interface also known as the Graphical User Interface.


So the first thing we are going to do is update the system. At the bottom of the screen you will see a little icon that looks like a shield. Hover the mouse over it. It will tell you if there are updates available.

Click on the icon. A window will pop up showing the updates are are available. Click Apply. A window will pop up saying Authenticaton is required . Enter you user password here. Click Authenticate. A window might pop up showing additional packages that also need to be installed.

Click Apply.

It will go through the process up updating the packages. Once finished it will show you the results and say your system is up to date. Check that icon from time to time to see if updates are available and install them.


Since we will be using this program allot I will tell you how to add it to your favorites menu on the desktop.

First click on the Menu start button on the lower left part of the screen.

Then click “All Applications”.

Find “Add/Remove Software” in the list and right click on it.

Then left click on “Add to Favorites” and there it appears.


Another program to become familiar with is the “Settings Manager”.

To access the “Settings Manager” again click on the start menu.

On the top bar of the window that pops up there is a button to the right of your username that looks like a wrench. The first button on the left. Click on it and it launches the Settings manager


Let’s talk about using LibreOffice. LibreOffice the the Office suite you installed when you installed Manjaro. It offers Windows equivalents of Word Excel Access Powerpoint. The equavalent programs are this:

Word > Writer

Excel > Calc

Access > Base

Powerpoint > Impress

You can open most all of your Microsoft Office documents in LibreOffice.

As you open the documents it knows what format they are saved in. If you make a change to one of them and go to resave it, it will prompt you which format to save in, Libreoffice or Microsoft.

For most cases you can save it in the Microsoft format. For more info on the differences between Libreoffice and Microsoft office there are many articles on the internet you can search on.


One of the next things to learn is the difference in the Microsoft vs Linux file system. In windows you are used to your system being the c: drive. There is no c: or any d: e: or anything like that in Linux.


Linux filesystems are built around a single root directory (/). All other directories and devices are attached to this root, creating a unified directory tree. For instance, user directories are in /home, system configuration files in /etc, and external devices might be mounted in /mnt or /media. In Linux, everything is treated as a file, including hardware devices.

So In Windows your documents directory would be in c:\Users\user\Documents

In Linux it would be in /home/user/Documents

Notice the \ backslash in Windows

Notice the / forward slash in Linux

Windows uses backslashes to navigate directories and Linux uses forward slashes.

So in windows you would navigate like cd \Documents

In Linux you would navigate like cd /Documents


Next item we want to tackle is dealing with printers.

The default Manjaro install most likely did not install your printer.

I have an HP printer so there are a couple of ways to install my HP printer. It is a wireless printer so Manjaro will find it via my wireless connection.


First we will install a package called “system-config-printer” with the add/remove software application we used above.

Goto Add/Remove Software and open it up.

In the search window type system-config-printer and hit enter.

You should get a list of packages and one of them is system-config-printer.

Click on the down arrow to install the package. Follow the prompts as you get them to complete the install.

You will know that it is installed when you see the down arrow icon change to a red trash can icon.

You can close the Add/Remove installer.

Click on the start menu. In the search bar type “printer”.

Click on “Print Settings”

If there are no printers configured it will say just that.

Click the Add button.

My printer is on my network so I will click the “Network Printer” selection.

Click on the appropriate printer that comes up in the list for your printer.

A selection will be highlighted then click “forward”.

If it found a driver for your printer you should see a dialog box that the title say “new printer”.

Click Apply

Click “Print Test Page”.

If everything worked correctly it should be printing a test page.

Click ok and you are done.
