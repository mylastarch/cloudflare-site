First Steps After Installing Linux Mint

A GUI-focused introduction for people moving from Windows.

On this page Update Linux Mint Use Software Manager Open System Settings Get to know LibreOffice Understand Linux file paths Check your printer Post-install checklist

Update Linux Mint

The first thing to do after installing Linux Mint is update the system. Look for the shield-shaped Update Manager icon near the bottom-right corner of the screen.

  1. Select the shield icon to open Update Manager.
  2. Review the available updates and select Apply.
  3. Enter your user password when authentication is requested.
  4. Approve any additional packages Linux Mint needs to install.
  5. Wait for the process to finish and confirm the system is up to date.

Check Update Manager regularly and install new updates when they become available.

Use Software Manager

Open the application menu in the lower-left corner and select Software Manager. This is the easiest graphical way to search for and install applications.

Software Manager can install common applications such as browsers, VLC, Steam, LibreOffice, and OBS. Linux Mint also supports Flatpak for applications distributed outside the traditional package repositories.

Open System Settings

Open the application menu again and select System Settings, normally shown near Software Manager. System Settings lets you configure hardware, themes, applets, extensions, startup applications, and other desktop preferences.

Get to Know LibreOffice

LibreOffice can open most Microsoft Office documents. When saving changes, it may ask whether you want to use a LibreOffice or Microsoft format. In many cases, you can continue using the Microsoft format when sharing files with Microsoft Office users.

Understand Linux File Paths

Windows organizes storage around drive letters such as C:. Linux starts with a single root directory, written as /, and attaches other directories and devices beneath it.

  • User files are normally stored under /home.
  • System configuration files are stored under /etc.
  • External devices may be mounted under /mnt or /media.

Windows: C:\Users\user\Documents

Linux: /home/user/Documents

Windows paths use backslashes (\), while Linux paths use forward slashes (/).

Check Your Printer

Linux Mint may automatically find many printers, particularly network-connected HP printers. Look for a printer icon near the bottom-right corner of the panel and select it to open the printer-jobs screen.

If your printer is not listed, open System Settings, find the printer configuration, and add it. Some models may require additional manufacturer software or drivers.

Post-Install Checklist

Immediate Actions

  • Run Update Manager: Refresh package information and apply all available updates.
  • Choose local mirrors: In Update Manager, open Edit → Software Sources and select nearby mirrors for faster downloads.
  • Install multimedia codecs: Search for Multimedia Codecs to enable support for additional audio and video formats.
  • Check hardware drivers: Open Driver Manager to detect proprietary drivers, including some NVIDIA graphics drivers.
  • Configure Timeshift: Create system snapshots so you can recover from a problematic update or configuration change.
  • Enable the firewall: Search for Firewall in the menu and enable it to block unauthorized incoming connections.

Customization and Optimization

  • Explore themes, applets, and extensions in System Settings.
  • Enable Night Light or Redshift to adjust screen color temperature at night.
  • Review Startup Applications and disable items you do not need at login.

Maintenance

  • Monitor storage and remove software or cached files you no longer need.
  • Use Mint’s backup tool for personal files in addition to Timeshift system snapshots.
