First things to do once you have installed Linux Mint


What we are going to do is go over some of the first steps you should do right after you install Linux Mint. Now since we are coming from being a Windows user I am going to look at this a just using the GUI interface also known as the Graphical User Interface.


So the first thing we are going to do is update the system. At the bottom of the screen you will see a little icon that looks like a shield. Hover the mouse over it. It will tell you if there are updates available.

Click on the icon. A window will pop up showing the updates are are available. Click Apply. A window will pop up saying Authenticaton is required . Enter you user password here. Click Authenticate. A window might pop up showing additional packages that also need to be installed.

Click Apply.

It will go through the process up updating the packages. Once finished it will show you the results and say your system is up to date. Check that icon from time to time to see if updates are available and install them.

One of the next things to learn is the difference in the Microsoft vs Linux file system. In windows you are used to your system being the c: drive. There is no c: or any d: e: or anything like that in Linux.


Linux filesystems are built around a single root directory (/). All other directories and devices are attached to this root, creating a unified directory tree. For instance, user directories are in /home, system configuration files in /etc, and external devices might be mounted in /mnt or /media. In Linux, everything is treated as a file, including hardware devices.

So In Windows your documents directory would be in c:\Users\user\Documents

In Linux it would be in /home/user/Documents

Notice the \ backslash in Windows

Notice the / forward slash in Linux

Windows uses backslashes to navigate directories and Linux uses forward slashes.

So in windows you would navigate like cd \Documents

In Linux you would navigate like cd /Documents

Immediate Actions (First 15 Minutes)

  • Run Update Manager: Click the shield icon in the bottom right, update package information, and apply all updates to ensure system stability.

  • Switch to Local Mirrors: In the Update Manager, go to Edit > Software Sources to select local mirrors for faster download speeds.

  • Install Multimedia Codecs: Search for "Multimedia Codecs" in the software manager or application menu to enable playback for various video/audio formats.

  • Install Hardware Drivers: Open the Driver Manager to detect and install proprietary drivers for components like NVIDIA graphics cards.

  • Configure Timeshift: Set up Timeshift (search in the menu) to create system snapshots. This allows you to restore your system if an update or configuration goes wrong.

  • Enable Firewall: Search for "Firewall" in the menu and enable it to block unauthorized incoming connections. 



System Customization & Optimization

  • Install Software: Use the Software Manager to install popular applications like Chrome/Brave, VLC, Steam, LibreOffice, or OBS.

  • Set Up Flatpak: Linux Mint supports Flatpak out-of-the-box for updated app versions.

  • Personalize Desktop: Explore Themes, Applets, and Extensions in the system settings to customize the look, feel, and functionality of the panel or desktop.

  • Enable Night Light (Redshift): Enable the built-in Redshift tool to automatically adjust screen color temperature for eye comfort at night.

  • Manage Startup Apps: Disable unnecessary applications from launching at login to speed up boot time. 

Maintenance

  • Clean System: Install and run tools like Stacer to monitor system resources and clean up cached files.

  • Configure Backup: Use the Mint backup tool to create backups of your personal files, separate from system backups.
